# agent-skills

Skills that let AI agents work with Accord through Accord's MCP server.

## Gong

Skills for Gong Custom Agents and Gong Assistant. Each `SKILL.md` is self-contained, so it can be pasted into Gong's agent builder as is.

| Skill | What it does |
|---|---|
| [`gong/create-deal-room`](gong/create-deal-room/SKILL.md) | Builds an unshared deal room from a discovery call |
| [`gong/deal-room-check-in`](gong/deal-room-check-in/SKILL.md) | Summarizes buyer engagement, overdue steps, and next actions (read only) |
| [`gong/update-plan-after-call`](gong/update-plan-after-call/SKILL.md) | Adds committed next steps from a call as seller-only steps |
